# Muhammad Asad Portfolio — V3

Editorial DTC / beauty / wellness direction.

## Design direction

- Warm bone / paper base instead of generic dark developer UI
- Forest + sage for wellness/technical sections
- Blush treatment for Legacare / beauty work
- Different visual composition for each case study
- Screenshot aspect ratios preserved instead of forced into identical cards
- Real project artifacts used as hero artwork
- Contact options: Email, LinkedIn and WhatsApp

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GSAP + ScrollTrigger (CDN)
- Google Fonts: Manrope + Instrument Serif
- Netlify (no build command required)

## Deploy

Replace your current project files with this version, then:

```bash
git add .
git commit -m "Redesign portfolio v3"
git push
```

Netlify should deploy automatically from the connected GitHub repository.
